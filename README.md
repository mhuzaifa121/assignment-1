# SC Assignment 01 — Object-Oriented Programming

Welcome to the repository for **Software Construction Assignment 01**.

This project demonstrates the implementation of important **Object-Oriented Programming (OOP)** concepts in Java through a series of practical tasks.

## 🎯 Assignment Overview

The main purpose of this assignment is to understand how OOP principles can be applied to design and improve Java programs.

### Concepts Demonstrated

* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Interfaces
* Constructors
* Method Overriding
* Data Validation
* AI Code Review and Refactoring

---

## 📂 Project Tasks

### 🔐 Task 1 — The Broken Vault

A `DigitalWallet` system is implemented to demonstrate **encapsulation and data protection**.

Key features include:

* Private data members
* Constructor-based initialization
* Balance validation
* PIN verification
* Controlled withdrawal operations
* Getter methods for required information

The task demonstrates how an object's internal data can be protected from direct modification.
